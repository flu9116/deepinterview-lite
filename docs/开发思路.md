# 开发思路

DeepInterview Lite 从一个日语实时语音 PoC 起步。最先验证麦克风、LiveKit、Deepgram、LLM 和 Kokoro 能否串起一轮问答。真人测试暴露了停顿被误判成答完、长句被拆开，以及语音首音偏弱等问题。练习保留自动判停和手动提交，方便把判停问题与转写、生成、播放问题分开定位。

## 两种模式

- 面试模式面向 Windows 桌面面试。Electron 分别采集麦克风和系统回环音频，保存独立音轨。实时转写和回答辅助按需开启。问题先在后台合并并判断完整性，前端只显示定稿，减少面试中阅读滚动草稿的负担。
- 练习模式面向可重复的日语模拟问答。基础、进阶和拟真实战的题型和题数由程序安排，LLM 生成岗位相关问题和追问。资料与 JD 作为参考数据进入模型。练习录音和转写可作为 ZIP 导出。
- 桌面主窗口和练习页各自拥有独立的渲染上下文。练习服务在本机回环地址启动，用户在同一窗口切换。运行包使用独立的 Windows 用户数据目录，开发环境可继续使用原工作目录。

## 代码入口

| 模块 | 职责 |
|---|---|
| `desktop/main.cjs`、`desktop/renderer.js` | Windows 桌面入口、录音、服务配置、单窗口切换。 |
| `desktop/live-session.cjs`、`desktop/question-gate.cjs` | 面试实时转写和问题合并判断。 |
| `src/server.ts`、`src/client.ts` | 练习界面和本地 API。 |
| `src/agent.ts`、`src/practice-plan.ts` | 语音会话、判停与练习流程。 |
| `tts_server/app.py` | Kokoro 日语合成。 |
| `scripts/build-windows.mjs`、`scripts/windows-installer.iss` | 从独立暂存目录生成 Windows 安装包。 |

## 从源码验证

Windows x64 下安装 Node.js 22 或更高版本，执行 `npm ci`、`npm run build:client` 和 `npm run desktop`。自动检查使用 `npm run typecheck`、`npm test`、`npm run test:desktop`。云端和麦克风功能还需要真人测试。脚本或测试中生成的语音样本只能用于工程对照。

Windows 安装包使用 Inno Setup 编译器。执行 `node scripts/build-windows.mjs <ISCC.exe的路径>`，构建程序从项目文件白名单生成安装暂存目录和安装程序。Kokoro 的 Python 环境与模型由使用者单独准备。当前保留已知的日语发音瑕疵，后续可用相同句子比较替代 TTS 引擎。
