# 发布者检查清单

Windows 安装包由 `scripts/build-windows.mjs` 从文件白名单构建。每次发布前检查：

- 明确本项目最终许可证、版权说明与第三方依赖清单。免费不自动代表开源。
- 逐项核对 Electron、Node／Python 依赖、Kokoro 模型、音色、分词／字典资源的授权和再分发条件；不要未经确认把整个开发虚拟环境或模型缓存打包。
- 用全新 Windows 用户／干净虚拟机测试，不继承开发者账号、模型缓存或环境变量。
- 排除所有真实 `.env`、密钥、加密设置、录音、PDF、转写、复盘、测试输出中的私人内容、浏览器缓存和开发目录。`.gitignore` 不会自动替你过滤手工压缩包。
- 仅打包审查过的必要文件。使用 `node scripts/check-release.mjs <独立发布暂存目录>` 做路径级辅助检查。脚本不读取归档内部，ASAR 应扫描其打包输入目录；路径检查不代替内联密钥和内容审计。
- 确认空配置可以本地录音；配置损坏不会静默恢复旧账号；清除配置后不会继续发送旧 Key。
- 验证保存、换 Key、清除、Deepgram／LLM／LiveKit／Kokoro 连接测试及同账号练习进程读取配置。修改后重启已有练习进程，确认新配置生效。
- 确认安装版的录音、资料及服务设置写入 `%APPDATA%\DeepInterviewLite-Installed`，并检查升级和卸载时数据仍可访问。
- 完成 Windows 系统音频、Teams 前台快捷键、45～60 分钟录音保存与异常恢复验收。
- 附上“发布说明.md”和“服务配置指南.md”；如果实际数据流、服务供应商或打包方式变化，同步更新。
- 不承诺自动封顶、准确账单、全厂商兼容或第三方 24 小时删除；当前没有实现这些保证。

本清单不宣称已经完成法律、安全或许可证审计。正式发布前仍需按最终发布包核验。
