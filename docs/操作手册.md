# DeepInterview Lite Windows 操作手册

## 安装与首次打开

1. 在 Windows 10 或 11 的 x64 电脑上运行 `DeepInterview-Lite-0.1.0-Windows-x64.exe`。安装向导默认安装到当前用户的 `%LOCALAPPDATA%\Programs\DeepInterview Lite`。
2. 从开始菜单打开 **DeepInterview Lite**。面试和练习共用一个窗口。安装包内含桌面和 Node 运行时。仅使用本地录音时，安装完成后即可开始。
3. 展开「服务与模型设置（用户自备账号）」。首次安装显示账号未配置。开发版已有的 `.env`、设置、录音和 PDF 不会导入安装版。模型名称和本机服务地址会显示程序默认值。

### 下载校验与 Windows 提示

1. 从项目的 [GitHub Releases](https://github.com/flu9116/deepinterview-lite/releases) 下载同一版本的 Windows 安装包和 `SHA256SUMS.txt`。在下载目录打开 PowerShell，执行以下命令。其他版本请换成实际文件名。

   ```powershell
   Get-FileHash -LiteralPath '.\DeepInterview-Lite-0.1.0-Windows-x64.exe' -Algorithm SHA256
   ```

   将输出的 `Hash` 与校验文件中同名安装包对应的值逐位比较。若不同，请停止安装，并从发布页重新下载。

2. 查看发布说明标注的签名状态。若该版本标为已签名，在安装包上右键选择「属性 → 数字签名 → 详细信息」，核对签名有效且发布者与发布说明一致。若标为未签名，Windows 可能显示「未知发布者」。SHA-256 用来核对下载文件，发布者身份由数字签名验证。
3. 如果 Windows 显示「Windows 已保护你的电脑」，并且提示是 SmartScreen 的「无法识别的应用」，在核对文件来源、哈希以及该版本应有的签名后，可按自己的判断选择「更多信息 → 仍要运行」。如果系统明确检出威胁、签名无效，或单位设备策略禁止运行，请停止安装并联系发布者或管理员。保持 Windows 安全防护开启。

已签名的新版本也可能因为下载信誉尚未建立而显示 SmartScreen 提示。[微软 SmartScreen 说明](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)

## 按用途配置服务

| 用途 | 所需服务 |
|---|---|
| 面试双路录音 | 无。关闭「实时转写与日语回答辅助」。 |
| 面试实时转写 | Deepgram。 |
| 面试日语要点和 AI 复盘 | Deepgram 和兼容 OpenAI Chat Completions 的 LLM。生成复盘需要已保存的转写。 |
| 日语语音练习 | LiveKit、Deepgram、LLM 和本地 Kokoro。 |

- 在服务商控制台自行创建账号和 API 凭据。填写 Deepgram Key、LLM Key 和模型，练习另外填写 LiveKit 项目 URL、Key 和 Secret。保存后，逐项点击测试按钮。LLM 文本请求通过后，仍应实际跑一次追问和复盘，确认模型支持相应请求。
- 密码框留空表示保留已有值。替换 Key 时填新值并保存，移除时勾选对应的清除选项。清除本地配置后，如需撤销旧 Key，请到服务商控制台操作。
- 服务方按各自规则计费。转写、LLM、LiveKit 及其云端判停可能计入各自用量。软件没有充值入口、统一账单或费用上限。只录音时无需开启云服务。
- 深入配置和换 Key 的操作见[服务配置指南](服务配置指南.md)。

### 第一次配置 Kokoro

1. 安装 **64 位 Python 3.12** 和 `py` 启动器。在 PowerShell 执行 `py -3.12 --version`，确认能找到 Python。
2. 使用默认安装位置时，在 PowerShell 执行以下命令。如果安装时另选了目录，把第一行替换成实际安装目录下的 `resources\app`。

   ```powershell
   $app = Join-Path $env:LOCALAPPDATA 'Programs\DeepInterview Lite\resources\app'
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $app 'scripts\start-kokoro.ps1') -Installed
   ```

3. 首次运行要下载 Python 依赖、日语字典和模型，耗时取决于网络和磁盘。看到本地服务在 `127.0.0.1:8787` 启动后，留着该窗口，在助手内开始一次练习并听完第一题，让默认音色文件也完成下载。成功后可以停止手动启动的服务。以后打开练习页时，助手可以用已准备的环境在后台启动 Kokoro。
4. 使用其他音色时，也要先在可联网的 Kokoro 进程里完成一次朗读，供后续离线加载。遇到端口被占用时，先确认占用程序是否为自己已经启动的 Kokoro。

## 面试模式（Windows Teams 桌面客户端）

1. 打开 Teams 和助手，选择实际讲话用的麦克风。开始双路录音前，确认对方声音从 Windows 默认播放设备输出。
2. 点击「开始双路录音」。说一句话，再用 Teams 测试通话或播放一小段音频，分别观察麦克风和系统音频电平。麦克风轨记录我方，系统音轨记录电脑播放的声音。系统通知、音乐或其他应用也可能被录入。
3. 需要实时辅助时勾选对应选项。先导入可选的 PDF，选中本场使用的资料。系统会在问题相对完整后显示日语要点。资料不足或转写不准时，请自行核对输出。
4. 轮到自己提问时，可打开「我方提问中」，或用全局快捷键 `Ctrl + Alt + Shift + Q`。这会暂停回答辅助，双方录音和转写继续。再次切换可恢复辅助。快捷键冲突时，使用手动开关。
5. 点击「暂停」可临时停录，点击「继续录音」恢复。结束后点击「结束并保存」。在「本地录音与复盘」回听两条音轨、导出转写或生成复盘。

## 练习模式

1. 点击「练习模式 → 打开练习」。首次启动模型和语音服务可能需要约一分钟。确认设置测试成功后，再点「开始练习并开启麦克风」。
2. **基础练习**无需 JD。勾选常见题，之后有两道追问。**进阶练习**需要 JD，围绕四个岗位主题各问一题并追问一次。**拟真实战**合并两类问题，需要 JD，约 35 分钟进入收尾，40 分钟停止接收回答。暂停时间计入拟真实战总时长。
3. JD 最多 3000 字符。个人 PDF 可选，选中后可用于生成更有针对性的提问。可在开始前取消「保存本轮练习录音」。
4. 等问题读完再回答。回答结束会自动判停，也可点击「回答完毕」。需要重听时点击「重播问题」。`暂停` 会停止收音和播放，恢复后可以继续当前练习。`重新开始` 开启一轮新练习。
5. 点击「结束测试」，等到提示本轮已保存，再点击「一键导出」。ZIP 内含转写和已开启且成功录制的语音。切换模式或关闭软件时，先完成保存。以前的 ZIP 可从「练习复盘 → 已保存的练习」再次导出。

## 文件、隐私和卸载

- 安装版数据默认位于 `%APPDATA%\DeepInterviewLite-Installed`。`recordings` 存放面试录音、转写和 `practice` 复盘包，`profiles` 保存导入的 PDF，`services.dpapi` 是当前 Windows 用户加密的服务配置。练习诊断数据可能包含转写，请勿直接公开整个目录。
- 录音文件在本地生成。开启实时转写时，音频会发送到 Deepgram。语音练习会通过 LiveKit 传输麦克风音频。回答辅助和追问会按需发送转写、JD 和相关 PDF 文本片段给配置的 LLM。服务商的数据处理方式以使用的账号和服务设置为准。
- 使用前确认所在组织和面试场景允许录音、云端转写及回答辅助。谨慎处理简历、招聘资料、面试题、录音和导出的 ZIP。不要将带真实资料的截图、复盘、密钥或诊断日志发到公开 Issue。
- 卸载程序后，用户数据目录保留，便于重新安装和取回录音。需要删除时先备份，再关闭应用并手动移除该目录。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 面试只录到自己 | 检查 Teams 的输出设备和 Windows 默认播放设备，并观察系统音频电平。 |
| 练习没有转写 | 检查麦克风权限和设备，再测试 Deepgram、LiveKit 配置。 |
| 有转写但没有追问 | 等自动判停或点「回答完毕」，再检查 LLM 测试、额度和模型。 |
| 有问题文字但没有语音 | 检查 Kokoro 服务和模型是否已准备好，可先按文字作答或重播。当前日语音色偶尔会弱化部分音节。 |
| 练习无法保存 | 保持当前页面打开，确认磁盘空间和用户数据目录可写，再点「重试保存」。 |
| 服务能测试但练习仍失败 | 单项测试只覆盖最小请求。检查模型功能、云端网络及语音环境，再开一轮短练习。 |
