# DeepInterview Lite：免费使用与第三方服务说明

适用版本：0.1.0 Windows x64。安装与操作步骤见[操作手册](操作手册.md)。

## 软件免费不等于第三方服务免费

DeepInterview Lite 计划免费提供。录音、保存、回放、PDF 本地解析与管理、已有转写导出等本地功能，不收取软件内按次费用。

联网 AI 功能需要用户自行注册服务商账号、开通 API、充值并配置凭据。费用由用户直接向相应服务商支付，本软件不代充值、不代收服务费用，不附送公共付费账号。免费额度、模型供应和单价由服务商决定，可能变化。

| 服务 | 主要用途 | 费用与条件 |
|---|---|---|
| Deepgram | 面试双路实时转写、练习语音识别 | 按服务商模型及音频用量计费。双路分别发送，不应只按面试墙钟时长估算 |
| 用户选择的 OpenAI 兼容 LLM | 回答要点、必要的问题完整性判断、练习提问、复盘 | 通常按输入／输出 token 计费。资料、上下文、后台草稿、重试也可能产生用量 |
| LiveKit Cloud | 练习模式实时音频房间 | 根据套餐、连接用量和超额规则计费；面试模式不需要 LiveKit |
| LiveKit 云端音频判停 | 练习模式的 audio 判停选项 | 取决于托管方式、套餐和额度，不能保证永久免费 |
| 本地 Kokoro | 练习提问朗读 | 当前本地实现无按次云 API 费；需要用户安装运行环境和模型，占用电脑资源。远程自建服务费用另计 |

面试系统不直接上传本地完整录音文件；但开启实时转写时，会实时发送两路音频给识别服务。练习模式的语音还会经所配置的 LiveKit 服务传输。

费用以服务商账单为准，本软件不保证某次面试或练习的固定价格。连接测试也可能计入用量。当前没有自动读取余额、准确账单统计或硬性消费封顶功能；请在供应商账户中配置可用的预算、额度与提醒，确认其是否真正限制消费。

参考定价入口：[Deepgram](https://deepgram.com/pricing)、[OpenAI](https://developers.openai.com/api/docs/pricing)、[LiveKit](https://livekit.com/pricing)。使用其他兼容 LLM 服务时，以该服务商规则为准。

## 自备配置与替换范围

在桌面助手顶部展开“服务与模型设置”，输入自己的账号资料并保存。设置支持连接测试，测试不会使用个人 PDF 或实际面试录音。

- 转写：当前只适配 Deepgram，可换自己的 Key、现有模型与语言，不能仅通过填写其他网址就切换到任意识别厂商。
- LLM：可填写兼容 Chat Completions 的地址、模型与 Key。需要支持项目使用的流式输出、JSON 模式和参数；连接成功不代表全功能兼容。
- 练习连接：填写自己的 LiveKit 项目地址、Key 与 Secret。
- 朗读：填写 Kokoro 服务地址与日语音色。用户按手册准备 Python 环境和模型后，助手可以后台启动本机 Kokoro 服务。
- 可关闭“后台草稿”减少额外 LLM 调用，但最终要点、必要语义判断和复盘仍可能收费。

服务缺失时，本地录音仍可使用。未配置 Deepgram 时请关闭实时转写；只有转写账号而没有 LLM 时，可以转写但不生成回答辅助。完整语音练习仍需要其服务链路配置完整并已启动。

## 数据与隐私

- 本地保存：两路录音、转写、回答要点、复盘、导入 PDF 副本和提取文字。录音和这些资料文件当前不自动加密、不自动过期删除，请妥善保护电脑与备份。
- 转写服务：开启实时转写会发送音频，当前 Deepgram 请求设置退出模型改进选项。它不等同于所有服务商、所有日志都承诺在 24 小时内删除。
- LLM：会收到问题／会话文字、所选 PDF 的相关文字或节选。若填写练习岗位要求，还会收到该 JD 文本。练习使用有长度上限的 PDF 节选，不保证覆盖全文。复盘会发送本场转写及会话阶段标记。
- PDF：原 PDF 文件不直接上传至 LLM，但其提取文字可能发送。
- LLM 请求设置 `store:false`，但第三方兼容服务可能不支持或不按同样语义处理；服务商独立的日志、滥用监测与保留规则仍适用。本软件不承诺第三方零保留或统一 24 小时删除。
- 系统音频可能包含 Teams 以外应用的声音，当前不是 Teams 单进程隔离。请关闭无关声音，避免录入不应采集的信息。
- 用户应确认录音、云端转写及实时辅助的使用符合所在场合、组织和平台要求，不要处理自己无权提供的个人或机密资料。

## 密钥保存与清除

服务设置使用 Windows 当前用户的 DPAPI 加密。安装版保存在 `%APPDATA%\DeepInterviewLite-Installed\services.dpapi`，开发版保存在 `%APPDATA%\DeepInterviewLite\services.dpapi`。设置页不会回显保存的完整 Key。练习进程启动时使用当时已保存的配置。

加密文件不是可跨电脑通用的凭据备份。换 Windows 账号／电脑后可能无法解密，需重新填写。此保护也不能阻止已经控制同一 Windows 账号的恶意程序。

密码框留空表示保留已有凭据。勾选单项清除才删除该凭据；“清除账号并恢复默认”会确认后清除软件配置，不删除录音和 PDF，不撤销供应商的密钥。已启动的练习服务需重启。源 `.env` 不会被修改，但加密配置存在后不再回退该文件的旧账号。
