# 新手入门｜从下载安装到第一次使用

## 1. 下载并打开软件

1. 确认电脑使用 Windows 10 或 11，系统类型为 x64。可以在「设置 → 系统 → 关于」查看。
2. 打开 [GitHub Releases](https://github.com/flu9116/deepinterview-lite/releases)，展开对应版本的 **Assets（附件）**，下载 `DeepInterview-Lite-0.1.0-Windows-x64.exe` 和 `SHA256SUMS.txt`。普通使用只需安装包和校验文件。请参照[操作手册的下载校验与 Windows 提示](操作手册.md#下载校验与-windows-提示)，核对后再双击 `.exe`。
3. 跟着安装向导完成安装。在 Windows 开始菜单搜索 **DeepInterview Lite** 并打开。看到「面试模式」和「练习模式」就进入主界面了。

## 2. 先录一段音，确认电脑能用

1. 进入「面试模式」，取消勾选「实时转写与日语回答辅助」。单纯录音无需注册任何服务。
2. 选择你说话时用的麦克风，点「开始双路录音」。对着麦克风说一句话，再用电脑播放一段你有权录制的测试音频。分别确认麦克风和系统音频的电平有变化。
3. 点「结束并保存」，在「本地录音与复盘」回听两条音轨。能听到自己的声音和电脑播放的声音，就可以使用本地录音了。
4. 如果某条音轨没有声音，先看 Windows「设置 → 隐私和安全性 → 麦克风」是否允许桌面应用使用麦克风，并检查播放器或会议软件的输出设备是否与 Windows 默认播放设备一致。

## 3. 按你想用的功能配置账号

API Key 是服务商发给你的访问密钥。软件免费，服务商可能按用量收费。请自行登录官方控制台创建凭据，将密钥直接填在软件的密码框内。注册、充值、设定额度由你在服务商控制台完成。

### 只想要实时转写

1. 在 [Deepgram 控制台](https://console.deepgram.com/)创建或选择项目，创建 API Key。
2. 在助手里展开「服务与模型设置（用户自备账号）」，把 Key 填到 **Deepgram** 区块的「API Key」。练日语可以先选「Nova-2 日语」，需要多语时可试「Nova-3 多语」。
3. 点击「保存服务设置」，再点「测试已保存的 Deepgram 连接」。连接通过后回到「面试模式」，勾选「实时转写与日语回答辅助」，开始一场短录音，确认界面出现转写。连接测试只验证服务连通，实时转写仍需实测。

### 还想要 AI 要点、复盘或语音练习

1. 在所用 LLM 服务商的控制台创建 API Key。例如使用 OpenAI 时，在 [OpenAI API 平台](https://platform.openai.com/)配置自己的 API 账号。确认所选模型可用，并检查账号额度。ChatGPT 登录账号或订阅与 API 用量分开管理。
2. 在助手的 **LLM** 区块填写「API 地址」「模型名称」和「API Key」。使用 OpenAI 时，API 地址是 `https://api.openai.com/v1`，模型名称可先用软件默认值，前提是你的 API 项目有权限调用。使用其他服务时，地址、模型和密钥都应来自同一服务商，并符合[兼容要求](服务配置指南.md)。
3. 点「保存服务设置」，再点「测试已保存的 LLM（会产生少量用量）」。如果你只想使用 AI 面试复盘，到这里即可试用。保存一场带转写的录音，再从录音列表生成复盘。

### 还想和 AI 进行日语语音练习

1. 在 [LiveKit Cloud 控制台](https://cloud.livekit.io/)创建或选择项目，找到项目 URL，创建一组 API Key 和 API Secret。
2. 在助手 **LiveKit** 区块依次填写「项目 URL」「API Key」「API Secret」。项目 URL 通常以 `wss://` 开头，三个值要来自同一个项目。点「保存服务设置」，再点「测试已保存的 LiveKit 认证」。
3. 在 [Python 官网](https://www.python.org/downloads/windows/)安装 **64 位 Python 3.12** 和 `py` 启动器。打开 PowerShell，输入 `py -3.12 --version`。看到 `Python 3.12.x` 后，按[操作手册的 Kokoro 配置步骤](操作手册.md#第一次配置-kokoro)运行安装包内置脚本。首次运行需要下载依赖和模型，请等到服务启动，再保留该 PowerShell 窗口。
4. 回到助手，在 **Kokoro** 区块保留默认地址 `http://127.0.0.1:8787` 和音色 `jf_alpha`。点「保存服务设置」，再点「检查已保存的 Kokoro 状态」。
5. 进入「练习模式 → 打开练习」，选择「基础练习」，不填岗位要求也可以开始。点「开始练习并开启麦克风」，等 AI 读完第一题，回答一两句后点「回答完毕」，确认收到追问。听到首题朗读后，默认音色也已完成首次加载。
6. 点「结束测试」，等到显示「本轮已保存」再尝试「一键导出」。能听题、收到追问并导出复盘，就完成了第一次语音练习。此后可以关掉手动启动 Kokoro 的窗口，再由助手启动已准备好的本机服务。

## 卡住时先检查这一项

| 你看到的情况 | 先做什么 |
| --- | --- |
| 测试还是使用旧设置 | 先点「保存服务设置」，然后重新点测试。已有练习要结束后再重新打开。 |
| 服务提示认证失败或额度不足 | 到相应服务商核对项目、密钥、额度和模型权限。密钥只填在软件中。 |
| Kokoro 状态检查失败 | 查看 PowerShell 是否已启动服务。首次下载报错时，先处理终端的第一条错误。 |
| 有录音但没有转写 | 检查 Deepgram 是否通过测试，以及面试模式是否勾选实时转写。 |
| 想请另一个 AI 一步步带你操作 | 复制 [AI 安装与配置提示词](AI安装与配置提示词.txt)。发错误信息前先遮盖密钥和个人资料。 |
