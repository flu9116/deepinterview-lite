# 服务配置与更换指南

## 设置入口

关闭旧助手，重新启动后，在顶部展开“服务与模型设置（用户自备账号）”。面试录音、生成复盘或测试期间，不修改设置。

安装版首次打开时需要自行填写服务账号，使用独立的用户数据目录。源码开发版兼容开发环境／`.env`，并保留原有设置。页面只显示“已配置／未配置”。点击保存后，将当前选项和保留的已有账号一起加密保存。

## 面试模式最小配置

1. 仅录音：无需服务账号；关闭“实时转写与日语回答辅助”。
2. 加转写：填写 Deepgram Key，选择模型，保存后测试。
3. 加回答辅助和复盘：填写 LLM Key、API 地址和模型，保存后测试。默认地址为 `https://api.openai.com/v1`，模型名称可改。模型可能更新或停用，以供应商实际支持为准。

面试模式从下一场使用新配置。STT 设置是默认值，面试页仍可为本场选择日语、多语或中文。

## 练习模式额外配置

填写 LiveKit 项目 URL（通常 `wss://…`）、Key 和 Secret。Kokoro 默认地址 `http://127.0.0.1:8787`，日语音色 `jf_alpha`。未准备语音环境的电脑需按[操作手册](操作手册.md)完成一次性安装和模型下载。

保存后，点击桌面助手的「练习模式 → 打开练习」。助手启动练习所需的本机服务和 Agent，并在当前窗口显示练习页。已运行的 Kokoro 可复用，助手只停止自己启动的服务。修改设置前请先结束并保存练习，切回面试模式修改，再重新打开练习。

`audio` 使用云端判停，可能产生 LiveKit 推理费用；`semantic` 需要本地语义模型资源，`vad`／`stt`／`manual` 是现有替代选项，但切换可能改变停顿与打断表现，不保证相同体验。

### 练习类型

- 基础练习无需 JD，可勾选要练的常见题，之后根据回答追问两题。
- 进阶练习须在「目标公司／岗位要求」填入招聘 JD（最多 3000 字），按四个岗位主题各问一题并追问一题。个人 PDF 可选。
- 拟真实战须填写 JD，合并两类题目并按实际经过时间计时（含暂停）。题目提前问完时会继续追问。约 35 分钟后在本轮答完时收尾，40 分钟停止接受回答。

练习自动判停的最短静音阈值为 2.3 秒。也可以在说完后手动点「回答完毕」提交当前回答。提交后，麦克风声音不会打断正在生成的追问，仍可通过「暂停」主动中断。

岗位要求作为参考文本发送给所配置的 LLM，请勿粘贴机密信息。修改岗位要求请先结束本轮，再开始新一轮。

### 练习录音与导出

桌面练习默认勾选「保存本轮练习录音」，可在开始前取消。录音混合麦克风回答与实际播放的 AI 朗读，暂停期间不录入；转写单独保留。关闭窗口前先点「结束测试」，等待「本轮已保存」，再点「一键导出」获取 ZIP，内含 `transcript.txt` 和开启录音时的 `practice.webm`。以前保存的练习也能从「练习复盘 → 已保存的练习」重新导出。归档在项目的 `recordings/practice`，不会自动发送给外部 AI。旧练习没有录音，无法补生成归档。

## 保存、换 Key 与清除

- 输入新的 Key 后保存即替换；密码框留空保留原值，不是删除。
- 删除单项：勾选对应“清除”并保存。
- 更换 LLM 域名时必须同时替换或清除旧 Key；更换 LiveKit 项目域名也必须同时替换／清除旧项目凭据。
- 清除全部：点击“清除账号并恢复默认”，确认后不再回退开发环境的旧凭据。没有删除原 `.env`，没有撤销供应商账号。
- 无法解密：不要共享加密文件或尝试复制别人的凭据，确认清除后使用自己的账号重新配置。

测试按钮始终测试已保存配置，尚未保存的输入不参与测试。LLM 使用固定短文本；Deepgram 只握手不发送录音；LiveKit 验证管理接口；Kokoro 只请求 `/health`。测试不证明流式、JSON、实际音频和模型资源全部正常，应再做短语音练习。

自定义 LLM 服务需要兼容 Chat Completions、流式 SSE、JSON 模式和 `store:false`、`max_completion_tokens` 等参数。仅修改 Key 不会自动适配所有厂商。当前不提供本地 STT 或自动安装本地 LLM 的功能。
